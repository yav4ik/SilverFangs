# «Серебряные клыки» · Arma Reforger

Сайт игрового сообщества Arma Reforger: программа «Второй шанс», заявки на вступление и закрытый архив с доступом по категориям участников.

## Запуск

Достаточно Python 3.12+; сторонних зависимостей для работы сайта нет.

```bash
cd /home/yav4ik/projects/XIIIth_site/silver-fangs
python3 server.py --host 0.0.0.0 --port 8088
```

Сайт: `http://81.85.73.48:8088/`, проверка состояния: `/health`.

На текущем сервере сайт запущен пользовательским сервисом systemd `silver-fangs.service`, включён автозапуск. Для пользователя включён linger, поэтому сервис продолжает работать после выхода из SSH.

```bash
systemctl --user status silver-fangs
systemctl --user restart silver-fangs
journalctl --user -u silver-fangs -n 50 --no-pager
```

Файл сервиса: `/home/yav4ik/.config/systemd/user/silver-fangs.service`.

## Первый вход администратора

Открой `/account` и войди с логином `admin`. Случайный начальный пароль находится в `.local-admin.txt` рядом с `server.py`; файл доступен только владельцу и не выдаётся веб-сервером. Пароль не включён в исходники. После входа его можно изменить в личном кабинете.

Панель `/admin` содержит:

- **Заявки:** скачивание вложения, контакт кандидата, решение и комментарий, назначение категорий.
- **Участники:** изменение категорий и отзыв доступа.
- **Материалы:** добавление, редактирование и удаление статей архива.
- **Права доступа:** названия и описания разделов; категории, которым они доступны.
- **Содержание:** описание проекта, название и текст программы, скачиваемый образец заявки.

Кандидаты регистрируются, скачивают образец, прикрепляют TXT, MD, PDF или DOCX до 5 МБ. Статус заявки отображается в личном кабинете. Возвращённую заявку можно исправить и отправить заново. Одобренному участнику архив открывается с назначенными категориями.

## Архив и категории

Начальные категории пользователя: «Участник», «Ветеран», «Командование». У пользователя может быть несколько категорий; доступ к разделу открывается при совпадении хотя бы одной. Администратор имеет полный доступ. Изменения прав применяются на сервере немедленно, в том числе при прямом обращении к API материала.

Разделы: «Архив контактов», «Внутренняя справка», «Справочник субъектов», «Архивные материалы». Стартовый доступ: контакты — ветеранам и командованию; остальные разделы — всем трём категориям. Настройки можно изменить в админке. Статьи изначально не заполнены: исходных текстов проекта пока нет.

Описание проекта, программа и образец заявки — редактируемые стартовые тексты. Они не представляют подтверждённую историю клана.

## Хранение и резервные копии

Данные сохраняются в SQLite `data/clan.sqlite3`, вложения — в `data/uploads/`. Для согласованной резервной копии можно остановить сервис, скопировать каталог `data/` и запустить сервис вновь. Секрет `.local-admin.txt` хранить отдельно от публикуемых исходников. Файл БД, вложения, пароль администратора и Python-исходник через веб-сервер недоступны.

Переменные для отдельного окружения:

- `SILVER_FANGS_DATA` — каталог базы и вложений.
- `SILVER_FANGS_ADMIN_FILE` — путь к файлу начального пароля.
- `SILVER_FANGS_SECURE_COOKIE=1` — флаг Secure для cookie при работе через HTTPS reverse proxy.

Эта версия работает по HTTP на отдельном порту 8088. Для постоянной эксплуатации с паролями рекомендуется поставить её за HTTPS reverse proxy.

## Проверки

```bash
python3 -m unittest discover -s tests -v
```

Тесты работают с отдельной временной базой, не создают записи на рабочем сайте и не меняют его пароль. Проверяют подачу и рассмотрение заявки, проверку форматов, повторную подачу, назначение и отзыв прав, прямой доступ к закрытым материалам, CSRF и смену пароля с завершением других сессий.

Дополнительная проверка интерфейса `tests/browser_check.py` требует Playwright и Chromium. Также использует изолированную временную базу.

## Оформление и ресурсы

Адаптивный тёмный интерфейс с серебряным знаком волка и оливковыми акцентами. SVG-эмблема создана в коде; это стартовый знак, который можно заменить официальным логотипом клана.

Фоновая иллюстрация: `site/assets/forest.jpg` (imagegen).

Шрифты Golos Text и Oswald размещены локально; лицензии OFL находятся рядом с файлами шрифтов. Сайт не требует внешних CDN, аккаунтов или API для работы. Проект не связан с Bohemia Interactive.
